# CMS editor development planning

The prototype checklist and automatic-publication plan have been retired. Maintain the [CMS editor development decisions](../docs/cms-editor/README.md) instead of adding milestone plans here.

The chosen workflow is Save Draft, submit a publication PR, manually merge after required checks, then confirm the GitHub Pages deployment. See [design decisions](../docs/cms-editor/decisions.md), [deployment](../docs/cms-editor/deployment.md), and [validation](../docs/cms-editor/validation.md) for implementation constraints and release checks.
