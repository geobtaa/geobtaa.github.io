## Citation Field Definitions

| Category                     | Summary                                                                                                                                                                                       |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dataset Title                | Provide the complete title of the dataset.                                                                                                                                                    |
| File Type / Format           | Choose a format from the dropdown list or type in a custom value.                                                                                                                             |
| Version                      | Version or edition number of the data.                                                                                                                                                        |
| Persistent identifier or URL | Provide a static electronic location or persistent identifier (e.g., DOI or URL) used to access the dataset.                                                                                  |
| Creator                      | Provide the name of the individual, group, or organization responsible for creating or making the data. This field is equivalent to the term 'Author' and can include multiple creators.      |
| Publisher or Repository      | Identify the organization or entity responsible for making the dataset available through archiving, publishing, or distribution.                                                              |
| Year of Publication          | Indicate the year the dataset was published, which may represent a one-time or infrequent release for the cited version of the data.                                                          |
| Temporal Coverage            | Time period of the dataset (free text).                                                                                                                                                       |
| Date accessed                | Date you retrieved the dataset. If the Temporal Coverage or Year of Publication is unknown, use this field to provide some temporal context. Change the date as needed or toggle off to omit. |

</section>

## About this tool

Geospatial datasets often require details that general-purpose citation
generators overlook. This tool, developed by the BTAA-GIN, helps users create consistent, editable citations in
common styles.
