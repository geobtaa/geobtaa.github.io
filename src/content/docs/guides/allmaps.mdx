The BTAA Geoportal connects to [Allmaps](https://allmaps.org/), a free tool that lets you place scanned maps over modern maps. This process is called *georeferencing*.

You can use Allmaps to create, view, and edit **Map Overlays** right from the Geoportal. Allmaps works with map images that use the [IIIF standard](https://iiif.io/).

## Find Maps to Georeference

<Steps>

1. Visit the [BTAA Geoportal](https://geo.btaa.org/) and search for a place or topic. You can also leave the search box blank to browse everything.

2. Under **Resource Class**, select **Maps**.

3. Open the **Map Overlay** filter and select **False** to find maps without an Allmaps overlay.

4. Choose a map and open its resource page.

</Steps>

:::note
Not every map supports Allmaps. Look for one with an image viewer on the resource page.
:::

## Create a Map Overlay

<FloatFigure side="right" width="min(48%, 27rem)">

![The Map Overlay section with a Georeference this map with Allmaps link][def]

*Before georeferencing, the Map Overlay section provides a link to open the map in the Allmaps Editor.*

</FloatFigure>

<Steps>
1. Find the **Map Overlay** section on the resource page. Click **Georeference this map with Allmaps** to open the Allmaps Editor.
2. Follow the instructions in Allmaps to match locations on the scanned map with locations on a modern map.
3. Return to the Geoportal and refresh the resource page to see your new overlay.
</Steps>

<LinkCard title="For more help, visit the Allmaps website" href="https://allmaps.org/" />


## View and Edit Map Overlays

<FloatFigure side="right" width="min(48%, 27rem)">

![The Map Overlay section with links to view or edit a georeferenced map](@images/mapOverlay-after.png)

*After georeferencing, the Map Overlay section provides separate links for viewing the overlay and editing its control points.*

</FloatFigure>

To find maps that already have overlays, select **True** under the **Map Overlay** search filter.

Open a resource page and select the **Map Overlay** tab to view the map. The built-in Allmaps Viewer lets you zoom, move around, and adjust the transparency of the overlay.

The **Map Overlay** section on the resource page also includes links to:

- **View map in the Allmaps viewer**
- **Edit map control points with Allmaps editor**

:::tip
Allmaps let you explore scanned maps in your browser. They do not provide downloadable GeoTIFF files through the Geoportal.

For downloadable GeoTIFFs, use the Geoportal's **Georeferenced** filter.
:::
