- Significant technology and infrastructure modernization, including cloud migration, accessibility improvements, and custom API development
- [Geoportal](http://geo.btaa.org) growth (records, providers, usage)
- Launched initiative to preserve foundational geospatial datasets from major cities across Big Ten states to support longitudinal research
- Stronger cross-institution network built through new members, regular working groups, national leadership, and the annual BTAA GIS Conference
- Evidence of organizational maturity: convening a 2025 strategic planning retreat
- BTAA Library Programs folded GIN into its library services package in 2023 and with two-year committed funding rather than annual

### Impacts

**Impact #1: Member institutions are part of a spatial data infrastructure that provides discovery, access and now archiving.**

*\[(2020): Participating institutions are now part of a spatial data infrastructure\]*

*What was the need?* By 2021, member institutions had a shared spatial data infrastructure for discovery and access, but no way to take custodial responsibility for data itself

*What did we do?*

- Migrated to AWS (2022–23); built GBL Admin for metadata and content management
- Re-architected around a central metadata API — metadata as the durable core, the discovery interface as a replaceable layer on top of it
- Adopted a modular, service-oriented architecture; began making metadata reusable across systems rather than tied to one application
- Developed the GeoBTAA metadata profile and contributed to the OGM Aardvark schema, extending shared metadata standards beyond BTAA-GIN's own infrastructure
- Launched Urban Base Layers: partnerships with 4 major cities to preserve foundational geospatial datasets, with a framework built to scale to more

*What were the outcomes?*

- Capability that didn't exist in 2020: BTAA-GIN now holds custodial responsibility for data itself, not just metadata pointing to it elsewhere
- BTAA Geoportal now archives 98 datasets from 12 cities
- BTAA library services identified GIN as a model program and, on its own initiative, folded GIN into its package along with two-year committed funding rather than annual (include in executive summary as well)
