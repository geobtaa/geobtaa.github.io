## Guidelines for submission

The annual Big Ten GIS Conference provides an opportunity to showcase your creativity using GIS tools and techniques. You can submit either a static map (JPEG, PNG, or SVG) or interactive map (i.e, story map, dashboard). We welcome all sorts of maps or apps regardless of any software platform you used to create/design them. Guidelines and format for the submission are given below:

## Static Map (digital)

### Required on your map

1. Title
2. Author(s)
3. Brief description of your map

### Map formatting and naming conventions

1. **File Type**: JPEG, PNG, or SVG.
2. **Dimensions**: Minimum resolution of 1920x1080 pixels to ensure clarity on larger screens (not applicable for SVG files).
3. **Aspect Ratio**: Recommended between 4 to 3 and 16 to 9. This ensures the map is easy to view on a typical computer monitor.
4. **File Name**: Use the following scheme: lastname\_firstname\_YYYY-MM-DD.jpg. 




:::note[Example file name title]

doe_jane_2026-03-01.jpg

:::


## Interactive/Dashboard

1. Title
2. Brief description of your map
3. Application's URL (must be publicly accessible)
4. Author(s)
